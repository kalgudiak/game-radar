# Game Radar

Collects every new game it can find across PC, consoles, iOS, Android and itch.io once a day,
puts each one into a single genre (plus mechanic-level sub-genres such as Merge, Runner,
Survivors-like, Idle RPG, Tower Defense), and writes a daily report.

## Setup

```bash
pip install -r requirements.txt
export TWITCH_CLIENT_ID=...       # free: dev.twitch.tv/console -> register an app (for IGDB)
export TWITCH_CLIENT_SECRET=...
python -m radar daily --lookback 14   # first run: backfill two weeks
python -m radar daily                 # every day after that
```

Other commands: `python -m radar collect --sources steam,itch`, `python -m radar report --date 2026-10-08 --basis released`,
`python -m radar trends --days 30`. Run `python -m pytest` for the parser and pipeline tests.

## What you get each day (`reports/YYYY-MM-DD/`)

| File | Contents |
|---|---|
| `report.html` | Filterable page: genre bands, platform filter, sub-genre filter, search, sortable columns. Each game title opens its main store page, with buttons for every other store and site |
| `summary.md` | Genre x platform count table, sub-genres seen, per-genre lists |
| `games.csv` | One row per store listing with every field, a column per store link (`steam_url`, `appstore_url`, `googleplay_url`, `itch_url`, `epic_url`, `playstation_url`, `xbox_url`, `eshop_url`, `website`) and `all_links` |
| `games.json` | One row per game, cross-store duplicates merged |
| `reports/trends/` | Genre counts by release day, and share/change vs the previous window |

`data/radar.db` (SQLite) keeps every game plus a daily snapshot of rating, rating count, installs
and price for the first 30 days after release, so you can spot breakouts:
`SELECT * FROM snapshots WHERE key='steam:123' ORDER BY day`.

## Sources and coverage

| Source | Platforms | How | Coverage |
|---|---|---|---|
| IGDB | PC, PS, Xbox, Switch, mobile majors, VR | Official API (Twitch auth) | Broad for PC/console; thinner for small mobile titles |
| Steam | PC/Mac/Linux | Newest-releases listing + appdetails + reviews; SteamSpy tags | Near-complete |
| App Store | iOS | Chart feeds for all 20 game categories per storefront + iTunes Lookup | New games that reach any chart (the commercially relevant slice) |
| Google Play | Android | Genre-seeded search + app pages (google-play-scraper) | Partial; Play has no public new-releases list |
| itch.io | PC/Web/Mac/Linux | Per-genre "newest" RSS feeds | Near-complete for recent uploads |

**Exhaustive mobile coverage** (every app published each day) is not available from free sources.
If you need it, add a source class for a paid provider (AppMagic, Sensor Tower, Appfigures,
42matters); each source is one file in `radar/sources/` implementing `fetch(start, end)`.

## Links

Every game carries its store page, plus whatever else the source knows: the developer website
(Steam, App Store, Google Play) and, from IGDB, links to Epic, GOG, PlayStation Store, Xbox, eShop,
Discord, YouTube and so on. When the same game is on several stores, all its links are merged.
Store pages are listed first, then the website, then community pages. Domain labels live in
`radar/links.py`.

## How genre is decided

`radar/taxonomy.py` maps every store's genre names, IGDB themes and Steam community tags to one
list of 26 genres. If a game maps to several, the most specific wins (Roguelike over Action,
Puzzle over Casual). Sub-genres are matched on title, tags and genres; a few noisy ones (Idle,
Runner, Co-op...) are never taken from descriptions. Edit `RAW_MAP`, `SUBGENRES` and the
`GENRES` priority order to fit how you think about the market.

## Behaviour notes

- Each run looks back `lookback_days` (default 3) because stores index late. Reports group by the
  day a game was first discovered by default; use `--basis released` to group by store date.
- Games found to be older than the window are remembered and never fetched again, so daily
  runs get cheaper after the first week. Pre-release titles are retried until launch day.
- A failing source is logged in the `runs` table and skipped; the others still run.
- Requests are rate-limited per host (`radar/http.py`). Steam, Apple and Google Play store pages are
  not official public APIs: keep the volume polite, set a real contact in `user_agent`, check each
  store's terms for your use, and check IGDB's terms for commercial use.
- Same-title games on different stores are merged in the report. Very generic titles
  ("Snake") can merge wrongly; the CSV keeps every listing separately.

## Daily dashboard (GitHub Actions + GitHub Pages)

Every morning at 07:00 IST the workflow collects new games, writes that day's report, rebuilds the
dashboard website and publishes it. The dashboard has the latest day, a day picker for every past
day, a Trends page (new games per day by genre, week-on-week genre and sub-genre changes) and a
CSV download per day. History is kept in `reports/`, so nothing is lost if the cache is cleared.

One-time setup (about 10 minutes):
1. Create a GitHub repository (for example `bomome/game-radar`) and upload everything in this folder,
   including the hidden `.github` folder and the `reports/` folder (it holds the first day of real data).
2. Settings > Pages > Build and deployment > Source: **GitHub Actions**.
3. Optional, for console games: Settings > Secrets and variables > Actions, add `TWITCH_CLIENT_ID` and
   `TWITCH_CLIENT_SECRET` (free app at dev.twitch.tv/console).
4. Actions > game-radar-daily > Run workflow, lookback `14`. The first run takes 30-60 minutes.
5. Your dashboard: `https://<your-account>.github.io/game-radar/`. It updates itself every day after that.

Privacy: a GitHub Pages site is public to anyone with the link (private sites need GitHub Enterprise),
and Pages from a private repository needs a paid GitHub plan. The data is all public store data, but if
you want the dashboard behind a login, deploy the `site/` folder to Cloudflare Pages with Cloudflare
Access instead (free for up to 50 people).

Build the site locally any time with `python -m radar site` and open `site/index.html`.

## Scheduling

On your own server instead of GitHub (then serve the `site/` folder with any web server):
`30 1 * * * cd /opt/game-radar && python -m radar daily >> radar.log 2>&1` (UTC).

"""Import data collected in a browser session (Steam / App Store / itch.io JSON exports)
into the radar database, so the normal classifier and report builder run on it."""
import json
import re
from pathlib import Path

from .dates import parse_date
from .links import add_link
from .models import Game
from .sources.itch import _SLUG_NAME
from .taxonomy import classify, norm_platform

_COUNT = re.compile(r"([\d,]+)\s+(?:user\s+)?reviews?", re.I)
_PCT = re.compile(r"(\d{1,3})%")


def _steam(g):
    if g.get("type") and g["type"] != "game":
        return None
    if not g.get("name"):
        return None
    rd = parse_date(g.get("rd")) or parse_date(g.get("listed"))
    txt = g.get("revtxt") or ""
    m, p = _COUNT.search(txt), _PCT.search(txt)
    cats = g.get("cats") or []
    links = add_link({"Steam": f"https://store.steampowered.com/app/{g['id']}/"}, g.get("web"), "Website")
    return Game(
        source="steam", source_id=str(g["id"]), title=g["name"], release_date=rd.isoformat() if rd else None,
        platforms=sorted({norm_platform(x) for x in g.get("plat") or ["windows"]}),
        raw_genres=g.get("genres") or [], tags=g.get("tags") or [],
        developer=g.get("dev") or None, publisher=g.get("pub") or None,
        price=g.get("price") if g.get("price") is not None else (0.0 if g.get("free") else None),
        currency=g.get("cur"), is_free=bool(g.get("free")), has_iap="In-App Purchases" in cats,
        rating=float(p.group(1)) if p else None,
        rating_count=int(m.group(1).replace(",", "")) if m else None,
        description=g.get("desc") or "", url=links["Steam"], icon_url=g.get("img") or "", links=links,
        extra={"review_label": g.get("rev") or None, "categories": cats},
    )


def _ios(a):
    rd = parse_date(a.get("rd"))
    links = add_link(add_link({}, a.get("url"), "App Store"), a.get("web"), "Website")
    price = a.get("price")
    return Game(
        source="appstore", source_id=str(a["id"]), title=a["name"], release_date=rd.isoformat() if rd else None,
        platforms=["iOS"], raw_genres=a.get("genres") or [], developer=a.get("dev"),
        price=price, currency=a.get("cur"), is_free=(price == 0) if price is not None else None,
        rating=round(a["rating"] * 20, 1) if a.get("rating") else None, rating_count=a.get("count"),
        description=a.get("desc") or "", url=a.get("url") or "", links=links,
        extra={"charts": a.get("charts") or []},
    )


def clean_itch_genres(games):
    """Drop genre labels whose feed returned exactly the same games as another feed."""
    by_slug = {}
    for g in games:
        for s in g.get("genres") or []:
            by_slug.setdefault(s, set()).add(g["url"])
    sets = list(by_slug.items())
    bogus = {a for a, sa in sets for b, sb in sets if a != b and sa == sb}
    for g in games:
        g["genres"] = [s for s in g.get("genres") or [] if s not in bogus]
    return bogus


def _itch(x):
    rd = parse_date(x.get("date"))
    try:
        price = float((x.get("price") or "").replace("$", "")) if x.get("price") else None
    except ValueError:
        price = None
    genres = [_SLUG_NAME.get(s, s.replace("-", " ").title()) for s in x.get("genres") or [] if s != "other"]
    return Game(
        source="itch", source_id=x["url"], title=x["name"], release_date=rd.isoformat() if rd else None,
        platforms=sorted({norm_platform(p) for p in x.get("plats") or []}) or ["Web"],
        raw_genres=genres, developer=x.get("dev"), price=price, currency="USD",
        is_free=price in (None, 0.0), description=x.get("desc") or "", url=x["url"], links={"itch.io": x["url"]},
    )


PARSERS = {"steam": _steam, "appstore": _ios, "itch": _itch}


def import_files(db, paths, day: str):
    counts = {}
    for p in paths:
        data = json.loads(Path(p).read_text(encoding="utf-8"))
        parse = PARSERS[data["source"]]
        if data["source"] == "itch":
            bogus = clean_itch_genres(data["games"])
            if bogus:
                print("itch: ignored unfiltered genre feeds:", ", ".join(sorted(bogus)))
        n = 0
        for raw in data["games"]:
            g = parse(raw)
            if g and g.release_date:
                db.upsert(classify(g), day)
                n += 1
        counts[data["source"]] = counts.get(data["source"], 0) + n
    db.commit()
    return counts

import argparse
import logging

import yaml

def load_config(path):
    p = Path(path)
    if not p.exists():
        p = Path(__file__).resolve().parent.parent / "config.yaml"
    return yaml.safe_load(p.read_text()) if p.exists() else {}


def main(argv=None):
    ap = argparse.ArgumentParser(prog="radar", description="Daily new-game radar, split by genre")
    ap.add_argument("--config", default="config.yaml")
    ap.add_argument("-v", "--verbose", action="store_true")
    sub = ap.add_subparsers(dest="cmd", required=True)
    for name, hlp in (("daily", "collect, then write today's report and 30-day trends"),
                      ("collect", "only collect and store"),
                      ("report", "only write the report for a day")):
        sp = sub.add_parser(name, help=hlp)
        sp.add_argument("--date", type=date.fromisoformat, default=date.today(),
                        help="run date, YYYY-MM-DD (default: today)")
        if name != "report":
            sp.add_argument("--sources", help="comma list, e.g. steam,itch (default: all enabled)")
            sp.add_argument("--lookback", type=int, help="override lookback_days (use 14+ on first run)")
        if name != "collect":
            sp.add_argument("--basis", choices=["discovered", "released"], default="discovered",
                            help="group by day first seen (default) or by store release date")
    ip = sub.add_parser("import", help="import JSON files exported from a browser session, then report")
    ip.add_argument("files", nargs="+")
    ip.add_argument("--date", type=date.fromisoformat, default=date.today())
    ip.add_argument("--note", default="", help="one line shown under the report headline")
    sp2 = sub.add_parser("site", help="build the dashboard website (site/) from all reports")
    sp2.add_argument("--out", default="site")
    tp = sub.add_parser("trends", help="genre counts over a window vs the window before")
    tp.add_argument("--date", type=date.fromisoformat, default=date.today())
    tp.add_argument("--days", type=int, default=30)
    a = ap.parse_args(argv)

    logging.basicConfig(level=logging.DEBUG if a.verbose else logging.INFO,
                        format="%(asctime)s %(levelname)s %(message)s")
    logging.getLogger("urllib3").setLevel(logging.WARNING)
    cfg = load_config(a.config)
    if getattr(a, "lookback", None):
        cfg["lookback_days"] = a.lookback
    db = DB(cfg.get("db_path", "data/radar.db"))
    reports = cfg.get("reports_dir", "reports")

    if a.cmd in ("daily", "collect"):
        only = set(a.sources.split(",")) if a.sources else None
        summary = collect(cfg, db, a.date, only)
        print("New games stored:", summary)
    if a.cmd == "import":
        from .browser_import import import_files
        print("Imported:", import_files(db, a.files, a.date.isoformat()))
        out, rows = write_daily(db, a.date, reports, "discovered", note=a.note)
        print(f"Report: {out} ({len(rows)} unique games)")
    if a.cmd in ("daily", "report"):
        out, rows = write_daily(db, a.date, reports, a.basis)
        print(f"Report: {out} ({len(rows)} unique games)")
    if a.cmd in ("daily", "site"):
        from .site import build_site
        out, days = build_site(reports, getattr(a, "out", "site"))
        print(f"Dashboard site: {out} ({len(days)} days)")
    if a.cmd in ("daily", "trends"):
        print("Trends:", write_trends(db, a.date, getattr(a, "days", 30), reports))

from datetime import date, datetime, timezone

_FORMATS = [
    "%d %b, %Y", "%b %d, %Y", "%d %B, %Y", "%B %d, %Y", "%d %b %Y", "%B %d %Y",
    "%a, %d %b %Y %H:%M:%S %z", "%a, %d %b %Y %H:%M:%S %Z", "%Y-%m-%d %H:%M:%S",
]


def parse_date(v):
    """Best-effort parse of the date formats the stores use. Returns date or None.
    Month-only or 'Coming soon' style values return None on purpose."""
    if v is None or v == "":
        return None
    if isinstance(v, date) and not isinstance(v, datetime):
        return v
    if isinstance(v, (int, float)):
        return datetime.fromtimestamp(v, tz=timezone.utc).date()
    s = str(v).strip()
    try:
        return datetime.fromisoformat(s.replace("Z", "+00:00")).date()
    except ValueError:
        pass
    for f in _FORMATS:
        try:
            return datetime.strptime(s, f).date()
        except ValueError:
            continue
    return None

import json
import re
import sqlite3
import unicodedata
from datetime import datetime, timezone
from pathlib import Path

from .models import Game

SCHEMA = """
CREATE TABLE IF NOT EXISTS games(
  key TEXT PRIMARY KEY, source TEXT, source_id TEXT, title TEXT, title_norm TEXT,
  release_date TEXT, genre TEXT, data TEXT, first_seen TEXT, last_seen TEXT);
CREATE INDEX IF NOT EXISTS ix_games_first_seen ON games(first_seen);
CREATE INDEX IF NOT EXISTS ix_games_release ON games(release_date);
CREATE INDEX IF NOT EXISTS ix_games_title ON games(title_norm);
CREATE TABLE IF NOT EXISTS rejected(source TEXT, source_id TEXT, PRIMARY KEY(source, source_id));
CREATE TABLE IF NOT EXISTS snapshots(
  key TEXT, day TEXT, rating REAL, rating_count INTEGER, installs INTEGER, price REAL,
  PRIMARY KEY(key, day));
CREATE TABLE IF NOT EXISTS runs(
  day TEXT, source TEXT, fetched INTEGER, added INTEGER, status TEXT, message TEXT, at TEXT);
"""


def norm_title(t: str) -> str:
    t = re.sub(r"[™®©℠]", "", t or "")   # strip before NFKD, which turns ™ into "TM"
    t = unicodedata.normalize("NFKD", t).encode("ascii", "ignore").decode().lower()
    t = re.sub(r"\b(the|a|an)\b", " ", t)
    return re.sub(r"[^a-z0-9]+", "", t)


def _merge_list(a, b):
    return list(dict.fromkeys(list(a or []) + list(b or [])))


class DB:
    def __init__(self, path):
        Path(path).parent.mkdir(parents=True, exist_ok=True)
        self.c = sqlite3.connect(path)
        self.c.row_factory = sqlite3.Row
        self.c.executescript(SCHEMA)

    def known_ids(self, source):
        rows = self.c.execute("SELECT source_id FROM games WHERE source=? UNION "
                              "SELECT source_id FROM rejected WHERE source=?", (source, source))
        return {r[0] for r in rows}

    def reject(self, source, source_id):
        self.c.execute("INSERT OR IGNORE INTO rejected VALUES(?,?)", (source, source_id))

    def upsert(self, g: Game, day: str) -> bool:
        """Returns True if this is a newly discovered game."""
        row = self.c.execute("SELECT data FROM games WHERE key=?", (g.key,)).fetchone()
        if row:
            old = Game.from_dict(json.loads(row["data"]))
            for f in ("platforms", "raw_genres", "tags", "subgenres", "languages"):
                setattr(g, f, _merge_list(getattr(old, f), getattr(g, f)))
            g.links = {**old.links, **g.links}
            g.extra = {**old.extra, **g.extra,
                       "charts": _merge_list(old.extra.get("charts"), g.extra.get("charts"))}
            self.c.execute("UPDATE games SET data=?, genre=?, last_seen=? WHERE key=?",
                           (json.dumps(g.to_dict()), g.genre, day, g.key))
            new = False
        else:
            self.c.execute("INSERT INTO games VALUES(?,?,?,?,?,?,?,?,?,?)", (
                g.key, g.source, g.source_id, g.title, norm_title(g.title), g.release_date,
                g.genre, json.dumps(g.to_dict()), day, day))
            new = True
        self.snapshot(g, day)
        return new

    def snapshot(self, g: Game, day: str):
        self.c.execute("INSERT OR REPLACE INTO snapshots VALUES(?,?,?,?,?,?)",
                       (g.key, day, g.rating, g.rating_count, g.installs, g.price))

    def recent_ids(self, source, since: str):
        return [r[0] for r in self.c.execute(
            "SELECT source_id FROM games WHERE source=? AND release_date>=?", (source, since))]

    def games_first_seen(self, day: str):
        return [Game.from_dict(json.loads(r["data"])) for r in self.c.execute(
            "SELECT data FROM games WHERE first_seen=? ORDER BY genre, title", (day,))]

    def games_released(self, day: str):
        return [Game.from_dict(json.loads(r["data"])) for r in self.c.execute(
            "SELECT data FROM games WHERE release_date=? ORDER BY genre, title", (day,))]

    def genre_counts(self, since: str, until: str):
        return self.c.execute(
            "SELECT release_date AS day, genre, COUNT(DISTINCT title_norm) AS n FROM games "
            "WHERE release_date BETWEEN ? AND ? GROUP BY release_date, genre", (since, until)).fetchall()

    def growth(self, key):
        return self.c.execute("SELECT day, rating, rating_count, installs FROM snapshots "
                              "WHERE key=? ORDER BY day", (key,)).fetchall()

    def log_run(self, day, source, fetched, added, status, message=""):
        self.c.execute("INSERT INTO runs VALUES(?,?,?,?,?,?,?)", (
            day, source, fetched, added, status, message[:500],
            datetime.now(timezone.utc).isoformat(timespec="seconds")))

    def commit(self):
        self.c.commit()
#### FILE: radar/http.py ####
import logging
import time
from urllib.parse import urlparse

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

log = logging.getLogger("radar")

# Seconds between requests to the same host. Conservative on purpose:
# Steam appdetails tolerates ~200 calls / 5 min, Apple's iTunes endpoints ~20/min.
HOST_INTERVALS = {
    "store.steampowered.com": 1.6,
    "steamspy.com": 1.0,
    "itunes.apple.com": 3.1,
    "api.igdb.com": 0.3,
    "itch.io": 1.5,
}


class Http:
    def __init__(self, user_agent: str, default_interval: float = 1.0, timeout: int = 30):
        s = requests.Session()
        retry = Retry(total=5, backoff_factor=2, status_forcelist=(429, 500, 502, 503, 504),
                      allowed_methods=frozenset(["GET", "POST"]), respect_retry_after_header=True)
        s.mount("https://", HTTPAdapter(max_retries=retry))
        s.mount("http://", HTTPAdapter(max_retries=retry))
        s.headers["User-Agent"] = user_agent
        self.s, self.timeout, self.default_interval = s, timeout, default_interval
        self._last = {}

    def _throttle(self, url):
        host = urlparse(url).netloc
        gap = HOST_INTERVALS.get(host, self.default_interval)
        wait = gap - (time.monotonic() - self._last.get(host, 0.0))
        if wait > 0:
            time.sleep(wait)
        self._last[host] = time.monotonic()

    def get(self, url, **kw):
        self._throttle(url)
        r = self.s.get(url, timeout=self.timeout, **kw)
        r.raise_for_status()
        return r

    def post(self, url, **kw):
        self._throttle(url)
        r = self.s.post(url, timeout=self.timeout, **kw)
        r.raise_for_status()
        return r

def label_for(url: str):
    host = (urlparse(url).netloc or "").lower().split(":")[0]
    for dom, label, group in _DOMAINS:
        if host == dom or host.endswith("." + dom):
            return label, group
    return "Website", 1


def add_link(links: dict, url: str, label: str = None):
    """Adds url to the links dict (label -> url) unless that label is already taken."""
    if not url or not str(url).startswith(("http://", "https://")):
        return links
    lab = label or label_for(url)[0]
    links.setdefault(lab, url)
    return links


def ordered(links: dict) -> dict:
    return dict(sorted(links.items(), key=lambda kv: (label_for(kv[1])[1], kv[0] == "IGDB")))

    currency: Optional[str] = None

    rating_count: Optional[int] = None
    installs: Optional[int] = None
    description: str = ""
    url: str = ""
    icon_url: str = ""
    content_rating: Optional[str] = None
    languages: list = field(default_factory=list)
    links: dict = field(default_factory=dict)         # label -> url (store pages, website, socials)
    extra: dict = field(default_factory=dict)
    # filled by the classifier
    genre: str = "Other"
    subgenres: list = field(default_factory=list)

    def from_dict(cls, d: dict) -> "Game":
        known = {k: v for k, v in d.items() if k in cls.__dataclass_fields__}

import logging
from datetime import date, timedelta

from .dates import parse_date

from .sources.base import SourceUnavailable
from .taxonomy import classify

log = logging.getLogger("radar")


def build_sources(cfg, http, only=None):
    out = []
    for name, cls in REGISTRY.items():
        scfg = (cfg.get("sources") or {}).get(name) or {}
        if only and name not in only:
            continue
        if not only and not scfg.get("enabled", True):
            continue
        out.append(cls(http, scfg))
    return out


def collect(cfg, db, run_day: date, only=None, sources=None):
    """Discover releases in [run_day - lookback, run_day], classify, store, then
    snapshot metrics for everything released in the last `track_days`."""
    start = run_day - timedelta(days=int(cfg.get("lookback_days", 3)))
    day = run_day.isoformat()
    http = Http(cfg.get("user_agent", "GameRadar/1.0"))
    sources = sources if sources is not None else build_sources(cfg, http, only)
    summary = {}
    for src in sources:
        src.skip = db.known_ids(src.name)
        fetched = added = 0
        try:
            for g in src.fetch(start, run_day):
                fetched += 1
                rd = parse_date(g.release_date)
                if rd is None:
                    continue                      # undated: try again tomorrow
                if rd < start:
                    db.reject(g.source, g.source_id)  # old game: never fetch again
                    continue
                if rd > run_day:
                    continue                      # pre-release; picked up on launch day
                classify(g)
                added += db.upsert(g, day)
            db.log_run(day, src.name, fetched, added, "ok")
            log.info("%s: fetched %d, new %d", src.name, fetched, added)
        except SourceUnavailable as e:
            db.log_run(day, src.name, fetched, added, "skipped", str(e))
            log.warning("%s skipped: %s", src.name, e)
        except Exception as e:
            db.log_run(day, src.name, fetched, added, "error", repr(e))
            log.exception("%s failed after %d items (kept what was stored)", src.name, fetched)
        db.commit()
        summary[src.name] = added

    since = (run_day - timedelta(days=int(cfg.get("track_days", 30)))).isoformat()
    for src in sources:
        ids = db.recent_ids(src.name, since)
        n = 0
        try:
            for g in src.refresh(ids):
                db.snapshot(g, day)
                n += 1
        except SourceUnavailable:
            pass
        except Exception:
            log.exception("%s refresh failed", src.name)
        if n:
            log.info("%s: refreshed metrics for %d tracked games", src.name, n)
        db.commit()
    return summary

LINK_COLUMN_LABEL = {"steam_url": "Steam", "appstore_url": "App Store", "googleplay_url": "Google Play",
                     "itch_url": "itch.io", "epic_url": "Epic Games Store", "playstation_url": "PlayStation Store",
                     "xbox_url": "Xbox Store", "eshop_url": "Nintendo eShop", "website": "Website"}
LINK_COLUMNS = list(LINK_COLUMN_LABEL)
SOURCE_RANK = {"igdb": 0, "steam": 1, "appstore": 2, "googleplay": 3, "itch": 4}
STORE_LABEL = {"igdb": "IGDB", "steam": "Steam", "appstore": "App Store", "googleplay": "Google Play", "itch": "itch.io"}


def _merge_links(gs):
    links = {}
    for g in gs:
        own = g.links or ({STORE_LABEL.get(g.source, g.source): g.url} if g.url else {})
        for label, url in own.items():
            links.setdefault(label, url)
    return [{"label": k, "url": v} for k, v in ordered(links).items()]


def cluster(games):
    """Merge the same title seen on several stores into one row."""
    groups = defaultdict(list)
    for g in games:
        groups[norm_title(g.title) or g.key].append(g)
    rows = []
    for gs in groups.values():
        gs.sort(key=lambda g: SOURCE_RANK.get(g.source, 9))
        rep = gs[0]
        plats = sorted({p for g in gs for p in g.platforms})
        best = max(gs, key=lambda g: g.rating_count or 0)
        rows.append({
            "title": rep.title,
            "genre": min((g.genre for g in gs), key=lambda x: PRIORITY.get(x, 99)),
            "subgenres": sorted({s for g in gs for s in g.subgenres}),
            "platforms": plats,
            "families": sorted({platform_family(p) for p in plats}, key=FAMILIES.index),
            "release_date": min((g.release_date for g in gs if g.release_date), default=""),
            "developer": next((g.developer for g in gs if g.developer), ""),
            "publisher": next((g.publisher for g in gs if g.publisher), ""),
            "price": next((g.price for g in gs if g.price is not None), None),
            "currency": next((g.currency for g in gs if g.currency), ""),
            "free": any(g.is_free for g in gs),
            "iap": any(g.has_iap for g in gs),
            "rating": best.rating, "rating_count": best.rating_count,
            "installs": max((g.installs or 0 for g in gs), default=0) or None,
            "charts": sorted({c for g in gs for c in g.extra.get("charts", [])}),
            "links": _merge_links(gs),
            "raw_genres": sorted({x for g in gs for x in g.raw_genres}),
            "tags": list(dict.fromkeys(t for g in gs for t in g.tags))[:12],
            "description": (rep.description or "")[:280],
            "icon": next((g.icon_url for g in gs if g.icon_url), ""),
        })
    rows.sort(key=lambda r: (PRIORITY.get(r["genre"], 99), -(r["rating_count"] or 0),
                             -len(r["charts"]), r["title"].lower()))
    return rows


def write_daily(db, day: date, out_root, basis="discovered", note=""):
    games = db.games_first_seen(day.isoformat()) if basis == "discovered" else db.games_released(day.isoformat())
    rows = cluster(games)
    out = Path(out_root) / day.isoformat()
    out.mkdir(parents=True, exist_ok=True)

    fields = ["source", "source_id", "title", "genre", "subgenres", "release_date", "platforms",
              "raw_genres", "tags", "game_modes", "developer", "publisher", "price", "currency",
              "is_free", "has_iap", "rating", "rating_count", "installs", "content_rating", "url"]
    with open(out / "games.csv", "w", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=fields + LINK_COLUMNS + ["all_links", "charts"])
        w.writeheader()
        for g in games:
            d = g.to_dict()
            row = {k: ("; ".join(map(str, d[k])) if isinstance(d[k], list) else d[k]) for k in fields}
            for col in LINK_COLUMNS:
                row[col] = g.links.get(LINK_COLUMN_LABEL[col], "")
            row["all_links"] = " | ".join(f"{k}: {v}" for k, v in ordered(g.links).items())
            row["charts"] = "; ".join(g.extra.get("charts", []))
            w.writerow(row)
    (out / "games.json").write_text(json.dumps(rows, indent=1, ensure_ascii=False), encoding="utf-8")
    (out / "summary.md").write_text(_markdown(day, rows, basis), encoding="utf-8")
    (out / "report.html").write_text(_html(day, rows, basis, note), encoding="utf-8")
    return out, rows


def _matrix(rows):
    m = defaultdict(Counter)
    for r in rows:
        for fam in r["families"] or ["Other"]:
            m[r["genre"]][fam] += 1
    return m


def _markdown(day, rows, basis):
    what = "newly discovered" if basis == "discovered" else "released"
    lines = [f"# New games, {day.isoformat()}", "",
             f"{len(rows)} unique games {what} (a game on several stores counts once).", ""]
    m = _matrix(rows)
    fams = [f for f in FAMILIES if any(m[g][f] for g in m)]
    by_genre = Counter(r["genre"] for r in rows)
    lines += ["| Genre | Total | " + " | ".join(fams) + " |", "|---|---:|" + "---:|" * len(fams)]
    for g in sorted(by_genre, key=lambda g: -by_genre[g]):
        lines.append(f"| {g} | {by_genre[g]} | " + " | ".join(str(m[g][f] or "") for f in fams) + " |")
    subs = Counter(s for r in rows for s in r["subgenres"])
    if subs:
        lines += ["", "**Sub-genres seen today:** " + ", ".join(f"{s} ({n})" for s, n in subs.most_common(15))]
    for g in GENRES:
        items = [r for r in rows if r["genre"] == g]
        if not items:
            continue
        lines += ["", f"## {g} ({len(items)})", ""]
        for r in items[:40]:
            bits = [", ".join(r["platforms"])]
            if r["developer"]:
                bits.append(r["developer"])
            if r["subgenres"]:
                bits.append("/".join(r["subgenres"]))
            if r["rating_count"]:
                bits.append(f"{r['rating']:.0f}/100 from {r['rating_count']:,} ratings" if r["rating"] else f"{r['rating_count']:,} ratings")
            if r["charts"]:
                bits.append(f"charting x{len(r['charts'])}")
            main = r["links"][0]["url"] if r["links"] else ""
            title = f"[{r['title']}]({main})" if main else r["title"]
            others = " · ".join(f"[{l['label']}]({l['url']})" for l in r["links"][1:])
            lines.append(f"- **{title}**: " + "; ".join(bits) + (f"  \n  {others}" if others else ""))
        if len(items) > 40:
            lines.append(f"- ...and {len(items) - 40} more in games.csv")
    return "\n".join(lines) + "\n"


def write_trends(db, end: date, days: int, out_root):
    start = end - timedelta(days=days - 1)
    prev_start = start - timedelta(days=days)
    cur = Counter()
    prev = Counter()
    daily = defaultdict(Counter)
    for r in db.genre_counts(prev_start.isoformat(), end.isoformat()):
        d = date.fromisoformat(r["day"])
        if d >= start:
            cur[r["genre"]] += r["n"]
            daily[r["day"]][r["genre"]] += r["n"]
        else:
            prev[r["genre"]] += r["n"]
    out = Path(out_root) / "trends"
    out.mkdir(parents=True, exist_ok=True)
    genres = [g for g in GENRES if cur[g] or prev[g]]
    with open(out / f"genre-by-day-{end.isoformat()}-{days}d.csv", "w", newline="") as f:
        w = csv.writer(f)
        w.writerow(["release_date"] + genres)
        for d in sorted(daily):
            w.writerow([d] + [daily[d][g] for g in genres])
    total, ptotal = sum(cur.values()) or 1, sum(prev.values())
    lines = [f"# Genre trends: last {days} days to {end.isoformat()}", "",
             "| Genre | Releases | Share | Prior period | Change |", "|---|---:|---:|---:|---:|"]
    for g in sorted(genres, key=lambda g: -cur[g]):
        ch = f"{(cur[g] - prev[g]) / prev[g] * 100:+.0f}%" if prev[g] else "new"
        lines.append(f"| {g} | {cur[g]} | {cur[g] / total * 100:.1f}% | {prev[g]} | {ch if ptotal else 'n/a'} |")
    p = out / f"trends-{end.isoformat()}-{days}d.md"
    p.write_text("\n".join(lines) + "\n", encoding="utf-8")
    return p

def _genre_colors():

    return {g: f"hsl({(i * 137.5) % 360:.0f} {58 if i % 2 else 48}% {46 if i % 2 else 40}%)"
            for i, g in enumerate(GENRES)}

"""Builds the dashboard website from the reports folder:

def _days(reports):
    return sorted((p.name for p in Path(reports).iterdir()
                   if p.is_dir() and (p / "report.html").exists() and p.name[:4].isdigit()), reverse=True)


def _nav(days, current, prefix):
    opts = "".join(f'<option value="{prefix}days/{d}.html"{" selected" if d == current else ""}>{d}</option>' for d in days)
    return (f'<nav class="sitenav" aria-label="Dashboard"><label>Day <select onchange="location.href=this.value">{opts}</select></label>'
            f'<a href="{prefix}index.html">Latest</a><a href="{prefix}trends.html">Trends</a>'
            f'<a href="{prefix}data/{current}.csv" download>Download CSV</a></nav>')


def build_site(reports="reports", out="site", window=30):
    reports, out = Path(reports), Path(out)
    days = _days(reports)
    if not days:
        raise SystemExit("No reports yet: run `python -m radar daily` first.")
    if out.exists():
        shutil.rmtree(out)
    (out / "days").mkdir(parents=True)
    (out / "data").mkdir()
    for d in days:
        html = (reports / d / "report.html").read_text(encoding="utf-8")
        (out / "days" / f"{d}.html").write_text(html.replace("<!--NAV-->", _nav(days, d, "../")), encoding="utf-8")
        if (reports / d / "games.csv").exists():
            shutil.copy(reports / d / "games.csv", out / "data" / f"{d}.csv")
    latest = (reports / days[0] / "report.html").read_text(encoding="utf-8")
    (out / "index.html").write_text(latest.replace("<!--NAV-->", _nav(days, days[0], "")), encoding="utf-8")

    series = []
    for d in sorted(days)[-window:]:
        rows = json.loads((reports / d / "games.json").read_text(encoding="utf-8"))
        series.append({"day": d, "genres": Counter(r["genre"] for r in rows),
                       "subs": Counter(s for r in rows for s in r["subgenres"]), "total": len(rows)})
    data = json.dumps({"series": series, "colors": _genre_colors(), "order": GENRES})
    (out / "trends.html").write_text(TRENDS.replace("__DATA__", data.replace("</", "<\\/"))
                                     .replace("<!--NAV-->", _nav(days, days[0], "")), encoding="utf-8")
    (out / ".nojekyll").write_text("")
    return out, days

def parse_rss(data):
    entries = ((data or {}).get("feed") or {}).get("entry") or []
    if isinstance(entries, dict):
        entries = [entries]
    out = []
    for e in entries:
        app_id = ((e.get("id") or {}).get("attributes") or {}).get("im:id")
        rel = parse_date((e.get("im:releaseDate") or {}).get("label"))
        if app_id:
            out.append((app_id, rel))
    return out


def parse_lookup(r, cc):
    if r.get("kind") != "software":
        return None
    genres = r.get("genres") or []
    if "Games" not in genres and r.get("primaryGenreName") != "Games":
        return None
    rd = parse_date(r.get("releaseDate"))
    price = r.get("price")
    avg = r.get("averageUserRating")
    size = r.get("fileSizeBytes")
    return Game(
        source="appstore", source_id=str(r["trackId"]), title=r.get("trackName", ""),
        release_date=rd.isoformat() if rd else None, platforms=["iOS"],
        raw_genres=[g for g in genres if g not in ("Games", "Entertainment")],
        developer=r.get("artistName"), publisher=r.get("sellerName"),
        price=price, currency=r.get("currency"), is_free=(price == 0) if price is not None else None,
        rating=round(avg * 20, 1) if avg else None, rating_count=r.get("userRatingCount"),
        description=r.get("description") or "", url=r.get("trackViewUrl") or "",
        icon_url=r.get("artworkUrl512") or r.get("artworkUrl100") or "",
        content_rating=r.get("contentAdvisoryRating"), languages=r.get("languageCodesISO2A") or [],
        links=add_link(add_link({}, r.get("trackViewUrl"), "App Store"), r.get("sellerUrl"), "Website"),
        extra={"storefront": cc, "version": r.get("version"), "min_os": r.get("minimumOsVersion"),

    def fetch(self, start, end):

        feeds = self.cfg.get("feeds", DEFAULT_FEEDS)
        genre_ids = self.cfg.get("genre_ids", DEFAULT_GENRES)
        yielded = set()

            for feed in feeds:

def chunks(seq, n):
    seq = list(seq)
    for i in range(0, len(seq), n):
        yield seq[i:i + n]

class GooglePlaySource(Source):
    name = "googleplay"

    def _lib(self):
        try:
            from google_play_scraper import app, search
            return app, search
        except ImportError as e:
            raise SourceUnavailable("pip install google-play-scraper to enable Google Play") from e

    def fetch(self, start, end):
        app, search = self._lib()
        lang = self.cfg.get("lang", "en")
        n = int(self.cfg.get("hits_per_query", 30))
        seen = set()
        for cc in self.cfg.get("countries", ["us"]):
            for q in self.cfg.get("queries", DEFAULT_QUERIES):
                try:
                    hits = search(q, lang=lang, country=cc, n_hits=n)
                except Exception as e:
                    log.debug("play search %r: %s", q, e)
                    continue
                for h in hits:
                    aid = h.get("appId")
                    if not aid or aid in self.skip or aid in seen:
                        continue
                    seen.add(aid)
                    try:
                        g = parse_app(app(aid, lang=lang, country=cc), cc)
                    except Exception as e:
                        log.debug("play app %s: %s", aid, e)
                        continue
                    if g:
                        yield g
        log.info("googleplay: checked %d unseen apps", len(seen))

    def refresh(self, ids):
        app, _ = self._lib()
        cc = self.cfg.get("countries", ["us"])[0]
        for aid in ids:
            try:
                g = parse_app(app(aid, lang=self.cfg.get("lang", "en"), country=cc), cc)
                if g:
                    yield g
            except Exception as e:
                log.debug("play refresh %s: %s", aid, e)

"""itch.io: per-genre 'newest' RSS feeds. High volume, lots of jam games, great for
spotting fresh mechanics early."""
import re
import xml.etree.ElementTree as ET

from ..dates import parse_date
from ..models import Game
from ..taxonomy import norm_platform
from .base import Source, log

FEED = "https://itch.io/games/newest/genre-{g}.xml"
FEED_ALL = "https://itch.io/games/newest.xml"
GENRES = ["action", "adventure", "card-game", "educational", "fighting", "interactive-fiction",
          "platformer", "puzzle", "racing", "rhythm", "role-playing", "shooter", "simulation",
          "sports", "strategy", "survival", "visual-novel", "other"]
_BRACKETS = re.compile(r"\s*\[[^\]]*\]")
_SLUG_NAME = {"card-game": "Card Game", "interactive-fiction": "Interactive Fiction",
              "role-playing": "Role-playing", "visual-novel": "Visual Novel"}


def parse_feed(xml_text, genre_slug=None):
    root = ET.fromstring(xml_text)
    games = []
    for it in root.iter("item"):
        t = lambda tag: (it.findtext(tag) or "").strip()
        link = t("link")
        title = t("plainTitle") or _BRACKETS.sub("", t("title"))
        if not link or not title:
            continue
        plats = []
        pnode = it.find("platforms")
        if pnode is not None:
            plats = [norm_platform(c.tag) for c in pnode if (c.text or "").strip().lower() in ("yes", "true", "1")]
        rd = parse_date(t("createDate")) or parse_date(t("pubDate"))
        price_txt = t("price").replace("$", "")
        try:
            price = float(price_txt) if price_txt else None
        except ValueError:
            price = None
        desc = re.sub(r"<[^>]+>", " ", t("description"))
        games.append(Game(
            source="itch", source_id=link.split("?")[0].rstrip("/"), title=title,
            release_date=rd.isoformat() if rd else None, platforms=sorted(set(plats)) or ["Web"],
            raw_genres=[_SLUG_NAME.get(genre_slug, genre_slug.title())] if genre_slug and genre_slug != "other" else [],
            price=price, currency=t("currency") or None, is_free=(price in (None, 0.0)),
            description=" ".join(desc.split()), url=link, icon_url=t("imageurl"), links={"itch.io": link},
            developer=link.split("//")[-1].split(".itch.io")[0] if ".itch.io" in link else None,
        ))
    return games


class ItchSource(Source):
    name = "itch"

    def fetch(self, start, end):
        merged = {}
        first_pages = {}   # slug -> frozenset of ids on page 1, to catch feeds whose genre filter was ignored
        max_pages = int(self.cfg.get("max_pages", 3))
        for slug in self.cfg.get("genres", GENRES) + [None]:
            for page in range(1, max_pages + 1):
                url = FEED.format(g=slug) if slug else FEED_ALL
                try:
                    games = parse_feed(self.http.get(url, params={"page": page} if page > 1 else None).text, slug)
                except Exception as e:
                    log.debug("itch %s p%d: %s", slug, page, e)
                    break
                if not games:
                    break
                if page == 1 and slug:
                    ids = frozenset(g.source_id for g in games)
                    dupes = [s for s, other in first_pages.items() if other == ids]
                    first_pages[slug] = ids
                    if dupes:
                        log.warning("itch: genre feed %s returned the same games as %s; ignoring its genre label", slug, dupes)
                        for g in games:
                            g.raw_genres = []
                        for s in dupes:
                            for m in merged.values():
                                m.raw_genres = [x for x in m.raw_genres if x != _SLUG_NAME.get(s, s.title())]
                for g in games:
                    if g.source_id in self.skip:
                        continue
                    if g.source_id in merged:  # same game in several genre feeds
                        merged[g.source_id].raw_genres = sorted(set(merged[g.source_id].raw_genres + g.raw_genres))
                    else:
                        merged[g.source_id] = g
                dates = [parse_date(g.release_date) for g in games if g.release_date]
                if dates and max(dates) < start:
                    break
        yield from merged.values()

"""Steam: the 'newest releases' search listing, then appdetails + review summary per new app.
Optional SteamSpy enrichment adds community tags, which drive much better genre splits."""
import html as htmllib
import re

from ..dates import parse_date
from ..links import add_link

from .base import Source, log

SEARCH = "https://store.steampowered.com/search/results/"
DETAILS = "https://store.steampowered.com/api/appdetails"
REVIEWS = "https://store.steampowered.com/appreviews/{}"
SPY = "https://steamspy.com/api.php"

_ROW = re.compile(r'<a[^>]+data-ds-appid="(\d+)"[^>]*>(.*?)</a>', re.S)
_TITLE = re.compile(r'<span class="title">(.*?)</span>', re.S)
_RELEASED = re.compile(r'class="[^"]*search_released[^"]*"[^>]*>\s*([^<]*?)\s*</div>', re.S)
_TAG = re.compile(r"<[^>]+>")
_MODES = {"Single-player", "Multi-player", "PvP", "Online PvP", "Shared/Split Screen PvP", "Co-op",
          "Online Co-op", "Shared/Split Screen Co-op", "MMO", "Cross-Platform Multiplayer"}


def parse_search(results_html):
    out = []
    for appid, inner in _ROW.findall(results_html or ""):
        t = _TITLE.search(inner)
        r = _RELEASED.search(inner)
        out.append((appid, htmllib.unescape(t.group(1).strip()) if t else "",
                    parse_date(r.group(1)) if r else None))
    return out


def parse_details(appid, d):
    if d.get("type") != "game":
        return None
    rd = d.get("release_date") or {}
    if rd.get("coming_soon"):
        return None
    rdate = parse_date(rd.get("date"))
    po = d.get("price_overview") or {}
    cats = [c.get("description") for c in d.get("categories") or []]
    langs = [x.strip() for x in _TAG.sub("", d.get("supported_languages") or "").replace("*", "").split(",") if x.strip()]
    langs = [l.split("languages with full audio")[0].strip() for l in langs if l]
    links = add_link({"Steam": f"https://store.steampowered.com/app/{appid}/"}, d.get("website"), "Website")
    plats = [norm_platform(p) for p, ok in (d.get("platforms") or {}).items() if ok]
    return Game(
        source="steam", source_id=str(appid), title=d.get("name", ""),
        release_date=rdate.isoformat() if rdate else None,
        platforms=sorted(set(plats)) or ["PC"],
        raw_genres=[g["description"] for g in d.get("genres") or []],
        game_modes=[c for c in cats if c in _MODES],
        developer=", ".join(d.get("developers") or []) or None,
        publisher=", ".join(p for p in d.get("publishers") or [] if p) or None,
        price=(po.get("final") / 100) if po.get("final") is not None else (0.0 if d.get("is_free") else None),
        currency=po.get("currency"), is_free=bool(d.get("is_free")),
        has_iap="In-App Purchases" in cats,
        description=d.get("short_description") or "",
        url=f"https://store.steampowered.com/app/{appid}/", icon_url=d.get("header_image") or "",
        content_rating=str(d["required_age"]) + "+" if str(d.get("required_age", "0")) not in ("0", "") else None,
        languages=langs[:40], links=links,
        extra={"categories": cats, "controller": d.get("controller_support"),

def apply_reviews(game, payload):
    qs = (payload or {}).get("query_summary") or {}
    total = qs.get("total_reviews")
    if total:
        game.rating_count = total
        game.rating = round(100 * qs.get("total_positive", 0) / total, 1)
        game.extra["review_label"] = qs.get("review_score_desc")

    def fetch(self, start, end):

def _map(term):
    return RAW_MAP.get((term or "").strip().lower(), "__unknown__")


def classify(game, max_tags: int = 8):
    """Sets game.genre and game.subgenres in place and returns the game."""
    strong_text = " | ".join([game.title or ""] + list(game.tags) + list(game.raw_genres))
    desc = (game.description or "")[:1200]

    subs, implied = [], []
    for name, rx, imp in _SUB_RE:
        if rx.search(strong_text):
            subs.append(name)
            if imp:
                implied.append(imp)
        elif name not in _DESCRIPTION_UNSAFE and rx.search(desc):
            subs.append(name)

    candidates = []
    for term in list(game.raw_genres) + list(game.tags)[:max_tags]:
        g = _map(term)
        if g and g != "__unknown__":
            candidates.append(g)
    candidates += implied

    game.genre = min(candidates, key=lambda g: PRIORITY[g]) if candidates else "Other"
    game.subgenres = subs
    return game

    if p in ("PC", "Mac", "Linux"):

from datetime import date

from radar.db import DB
from radar.models import Game
from radar.pipeline import collect
from radar.report import write_daily, write_trends
from radar.sources.base import Source


class Fake(Source):
    def __init__(self, name, games):
        super().__init__(None, {})
        self.name, self.games, self.calls = name, games, 0

    def fetch(self, start, end):
        self.calls += 1
        for g in self.games:
            if g.source_id not in self.skip:
                yield g


def G(src, sid, title, rd, genres, plats):
    return Game(source=src, source_id=sid, title=title, release_date=rd, raw_genres=genres,
                platforms=plats, rating_count=10, url=f"https://x/{sid}")


def test_end_to_end(tmp_path):
    db = DB(tmp_path / "r.db")
    day = date(2026, 10, 8)
    steam = Fake("steam", [G("steam", "1", "Star Grid Arena", "2026-10-08", ["Strategy"], ["PC"]),
                           G("steam", "2", "Ancient Classic", "2019-01-01", ["Action"], ["PC"]),
                           G("steam", "3", "Not Yet Out", "2026-12-01", ["Action"], ["PC"])])
    play = Fake("googleplay", [G("googleplay", "com.a", "Star Grid Arena™", "2026-10-07", ["Strategy"], ["Android"]),
                               G("googleplay", "com.b", "Word Wiz", "2026-10-08", ["Word"], ["Android"])])
    summary = collect({"lookback_days": 3, "track_days": 30}, db, day, sources=[steam, play])
    assert summary == {"steam": 1, "googleplay": 2}
    assert "2" in db.known_ids("steam")           # old game remembered as rejected
    assert "3" not in db.known_ids("steam")       # future game retried later

    out, rows = write_daily(db, day, tmp_path / "reports")
    titles = {r["title"]: r for r in rows}
    assert len(rows) == 2                          # cross-store duplicate merged
    assert titles["Star Grid Arena"]["platforms"] == ["Android", "PC"]
    assert titles["Word Wiz"]["genre"] == "Word & Trivia"
    for f in ("games.csv", "games.json", "summary.md", "report.html"):
        assert (out / f).stat().st_size > 0
    assert "| Strategy | 1 |" in (out / "summary.md").read_text()
    assert write_trends(db, day, 7, tmp_path / "reports").exists()

    # second run: nothing new, nothing re-fetched
    assert collect({"lookback_days": 3}, db, day, sources=[steam, play]) == {"steam": 0, "googleplay": 0}
